# Playwright workflow

Use headless Playwright by default, including for signed-in tasks. The user authorizes reusing their existing cookies and other authentication session data in a separate headless browser without additional approval. Reuse only what the task needs, keep session data private, and remove temporary session copies after the task. Use the user's currently open browser or attach to their existing browser session only when they explicitly request it for the current task. If headless access is unavailable, explain the limitation and ask before using their open browser.

Do not generate Playwright logs or log artifacts by default. Avoid enabling debug logging or saving browser, console, network, trace, video, or test-run output to log files. Keep routine Playwright output minimal. Generate logs or related artifacts only when the user explicitly asks for them or they are necessary to diagnose a specific issue.

The connected Playwright browser tool automatically writes page snapshots under `.playwright-mcp/` during navigation and can also leave `console-*.log` files there. The tool does not expose a way to disable the automatic snapshots. After each task using the tool, remove generated snapshots and logs unless the user explicitly requested their retention. Check the hidden `.playwright-mcp/` directory itself when confirming cleanup; reading this workflow does not verify that artifacts were removed.

When reusing this Linux Chromium profile in a separate Playwright browser, exclude Playwright's `--password-store=basic` and `--use-mock-keychain` defaults via `ignore_default_args`. Its stored cookies use the desktop keyring (v11); forcing the basic store caused copied Google authentication cookies to disappear and Google Voice to redirect to its public landing page. With the desktop D-Bus/keyring session available and those defaults excluded, the private temporary profile loaded the cookies and Google Voice login worked headlessly. Copy live cookie SQLite databases using SQLite backup, and delete the temporary profile afterward. Never print cookie values or save them in tracked files.
